# Meridian Payments — GCP delivery architect exercise

**Submission status: template ready; deployment and candidate verification NOT yet completed.** This repository is a starting implementation, **not** evidence that it runs in your Google Cloud project. Review the Terraform, run it in your own project, and document what you verified.

**Architecture:** Public `GET /health` → Cloud Run (private Direct VPC egress) → Cloud SQL PostgreSQL private IP, using Cloud SQL Python Connector and runtime Secret Manager reads. Separate private Cloud Run Job runs migrations on demand; developers trigger it from their laptops using `gcloud` and Google IAM. Terraform creates custom VPC, private services access, SQL, per-secret IAM, Artifact Registry, Cloud Run API/job and a versioned GCS state bucket (bootstrap state is migrated to GCS). Region: `europe-west1` (EU).

**Key decisions:** Cloud Run instead of GKE for one lightweight API; custom VPC instead of `default`; **no Cloud SQL public IP**; a private migration job rather than connecting laptops to PostgreSQL; no JSON service-account keys; Git commit-tagged images. Low-cost single-zone Cloud SQL and synthetic secrets are **not** production safe. The Terraform state includes generated credentials: tightly restrict state access; do not use real API tokens. Regional compute/secrets alone do not establish full legal data residency. See [ASSUMPTIONS.md](ASSUMPTIONS.md).

**Run:** Install Git, Terraform (1.6+), Google Cloud CLI, Docker and a Google Cloud project with billing. Authenticate with `gcloud auth login` and `gcloud auth application-default login`. Follow [SETUP-WINDOWS.md](SETUP-WINDOWS.md) (PowerShell) or [SETUP-LINUX-MAC.md](SETUP-LINUX-MAC.md) (Bash). Commit your reviewed changes, then run `scripts/deploy.ps1` or `scripts/deploy.sh`; scripts provision platform, build/push image, deploy API/job, and print the `/health` URL. Trigger the migration job with `gcloud run jobs execute meridian-migrate --region europe-west1 --wait`. Clean up **after review** with `scripts/destroy.*`; state bucket is retained.

**Verification:** `/health` returns `candidate`, actual deployed `commit`, `region`, `db`, `secret`. `db: ok` means `SELECT 1` succeeded on that request; `secret: ok` means Secret Manager returned two distinct secret versions on that request. Any check failure returns HTTP 503 and `error`. Check `infra/application` outputs. Run local unit tests with `pip install Flask pytest` then `pytest app/tests -q`.
